# NavPro visual overview

NavPro brings clash coordination and model review tools into Autodesk Navisworks Manage. The repository includes a high-resolution dashboard visual and a suite of compact ribbon icons.

## Feature gallery

| Workflow | NavPro tools |
|---|---|
| Clash review | Dashboard, Matrix Designer, Approver, Renamer |
| Model coordination | Refresh Models, Colorizer, Tolerance updater |
| Data exchange | Clash Status Import, report export |
| Set management | SearchSetCreater |
